Research, prototypes, and writing. Public website files for GitHub Pages.

This repository contains only reviewed, pre-built website pages and their
necessary public assets. It contains no private notes, original CV, hosting
credentials, or personal visitor data. Prototypes run locally in the browser.

Publish this repository as `YoshuaYang/yoshuayang.github.io`. In repository
Settings → Pages, keep Deploy from a branch with `main` and `/ (root)` as the
publishing source. GitHub publishes the static site after updates to `main`.
The .nojekyll file preserves the framework assets. No paid domain is required.

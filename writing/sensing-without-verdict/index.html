METHOD NOTE

技术可以感知人，但不必替人解释自己

从 EEG 的兴趣出发，保留信号、状态与意义之间的距离。

什么吸引了我

我对 EEG 的兴趣，来自一个很朴素的愿望：能否看见一些主观上尚未意识到的变化？信号如果成为可见、可听或可感的材料，可能让人以不同的方式注意自己。

我并不希望设备直接宣布我正在专注、放松，或者属于某种固定类型。我更感兴趣的是，它能否提供反思的入口，同时把解释留给使用者。

signal ≠ state ≠ meaning

在我的方法思考中，信号、状态与意义需要分开。一个被采集的变化，并不会自动说明一个人正处在什么状态；即使提出了状态的解释，也不能直接回答这段经验对这个人意味着什么。

从记录到判断，每一步都有选择。显示什么、忽略什么、使用什么标签，都会改变使用者与信号的关系。对我而言，人类学可以进入这些具体环节，关注人怎样描述、接受或反驳技术给出的语言。

把不一致留下来

如果屏幕上的变化与我的感受不同，交互应该容纳这种不一致。它可以让我重新注意情境，也可以让我说“这不是我的经验”。主观描述不应只是等待被设备校正的误差。

我目前从最小循环开始学习：信号进入电脑，经过简单处理，再驱动一个输出。网站上的波形是合成信号演示，不是我的脑电实验结果。它帮助我把问题变得具体：如何让变化可见，又不急着替人下结论？

据我的田野回顾与实践笔记整理、修订。
